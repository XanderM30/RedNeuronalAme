

\## Comparación entre la red neuronal y la fórmula directa



Se evaluó la red neuronal MLP con 1,000 muestras sintéticas

nuevas, generadas con una semilla diferente a la utilizada

para construir el conjunto de entrenamiento.



La red neuronal obtuvo un error absoluto medio (MAE) de

1.9144 puntos del IIRF y un error máximo de 9.3180 puntos.

El coeficiente de determinación R² fue de 0.9713 y la

exactitud de clasificación por categorías fue de 95.10 %.



En las mismas muestras, la fórmula directa obtuvo un MAE

de 0.0000 y un error máximo de 0.0000 frente al IIRF de

referencia. Este resultado se explica porque la fórmula

directa reproduce las reglas empleadas para calcular dicho

índice en los datos sintéticos.



Por lo tanto, los resultados demuestran que la red neuronal

puede aproximar el índice sintético, pero no que sea superior

a la fórmula directa. La evaluación utiliza datos simulados

y no constituye una validación experimental del rendimiento

de un filtro físico ni de la potabilidad del agua.



Como trabajo futuro, se contempla incorporar mediciones

reales de sensores, comprobar su calidad y calibración, y

evaluar el modelo con datos experimentales independientes.
